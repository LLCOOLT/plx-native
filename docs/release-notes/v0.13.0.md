# v0.13.0 — Live TV that sounds right, settings while you watch, faster artwork, and PlxNative on Mac and Windows

This release fixes the distorted sound on Tunarr channels that 0.12.0 did not, makes channels tune faster (4K ones included), lets you change settings while a channel plays, loads artwork sooner, and adds a desktop app for macOS and Windows.

## What's new

- **PlxNative for Mac and Windows.** This release comes with a desktop app beside the television package: **PlxNative-0.13.0-arm64.zip** (a Mac with Apple Silicon), **PlxNative-0.13.0-x86_64.zip** (an Intel Mac) and **PlxNative-0.13.0-windows-x64.zip** (Windows 10 and 11). It is the same interface, driven with the arrow keys, Enter and Esc (a right-click goes back too), and it plays video with its own bundled FFmpeg on the computer's hardware decoder. It stays signed in, keeping your Plex session in the Keychain on a Mac and in Windows' own data protection on a PC. Neither app is signed by a paid developer certificate, so the first time you open it macOS or Windows SmartScreen will ask you to confirm: the [Mac guide](https://github.com/l-tata/plx-native/blob/main/docs/macos-app-readme.md) and the [Windows guide](https://github.com/l-tata/plx-native/blob/main/docs/windows-app.md) say how.
- **Settings while a channel plays.** Press **Right** on a Live TV channel to open the player's menu; the banner says so. On one of your own channels it has **Audio & subtitles** and **Quality**, as for any film. A Tunarr channel is encoded by Tunarr itself, so it offers Stats for nerds there.
- **Channels tune faster.** A channel you have watched before starts at once, without reading the stream first, and a channel you have not watched spends less time being examined before the picture appears.
- **4K channels tune.** A very high-bitrate channel could fill the television's buffer before playback began and then never start; it now starts as soon as the buffer is full. A 4K H.264 channel is now set up as 4K rather than as 1080p.
- **Artwork arrives sooner.** Rows and grids now fetch the posters just past the edge of the screen, and the shelf below it, so a scroll arrives at artwork already on its way. Each artwork request also reuses the connection to your server instead of opening a new secure connection every time.

## Fixed

- **Live TV sound was distorted: stuttering and slightly high-pitched.** Tuning a channel sent the television about a second of sound stamped with a single moment in time, and the television then spent the whole viewing catching up. That sound is now dropped, as the picture before the first frame always was. The change 0.12.0 made for this was not the cause; see the correction in that note.

## Compatibility

- **Plays video, verified by watching it — the maintainer's own LG set.** Test builds of this release were watched on it before publishing: Live TV channels with the sound fix, which is confirmed, the settings menu, faster tuning and artwork. The set's model and platform release are not recorded in this note.
- **Starts, and nothing further is known — every other firmware from webOS 4.0 up is expected to start.** This binary's libraries and symbols are checked against the firmware images webosbrew has; the result for this build is in the [technical audit](https://github.com/l-tata/plx-native/blob/main/docs/release-audits/v0.13.0.md). That grades startup and says nothing about whether video plays.
- **The desktop apps are new in this release.** Each is built and started on the matching GitHub-hosted runner (macOS for Apple Silicon and Intel, Windows x64) before it is attached.

If your set is in the second group, [tell us what happened](https://github.com/l-tata/plx-native/issues). It working is as useful a report as it failing.

## Known issues

- **A very high-bitrate 4K channel has under a second of cushion.** The television's buffer for a channel holds 8 MB of video, which is less than a second above about 60 Mbit/s, so a pause in the network or in Tunarr's encoder can show as a brief stall. Raising that limit needs testing on the set first.
- **Styled (ASS/SSA) subtitles are not available in the Windows app yet.** The television and Mac builds have them.
- **A kept channel is saved as a visible playlist,** as in 0.12.0.

## Installing

Download **com.beb.plxnative_0.13.0_arm.ipk** and install it with the [Homebrew Channel](https://github.com/webosbrew/webos-homebrew-channel) or [dev-manager-desktop](https://github.com/webosbrew/dev-manager-desktop). You do **not** need a rooted TV.

Nothing in this distribution chain is signed, so this sha256 is what tells you the file you have is the file published here:

```
__IPK_SHA256__  com.beb.plxnative_0.13.0_arm.ipk
```

[Installing and checking a download](https://github.com/l-tata/plx-native/blob/main/docs/install-and-verify.md) covers the other assets, how to check the hash on each platform, and the Developer Mode expiry that uninstalls your apps. This package bundles FFmpeg under LGPL-2.1-or-later and its complete corresponding source is attached to this release. Exactly what was built, verified and shipped is in the [technical audit for v0.13.0](https://github.com/l-tata/plx-native/blob/main/docs/release-audits/v0.13.0.md).
